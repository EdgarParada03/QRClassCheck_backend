# QRClassCheck - Backend

Backend de la aplicación **QRClassCheck**, un sistema académico para el registro de asistencia mediante códigos QR.  
Este servicio está desarrollado en **Node.js** y desplegado en **Render**, utilizando **Firebase Firestore** como base de datos y **SendGrid** para el envío de reportes.

---

## 🚀 Funcionalidades principales

- Registro de asistencia mediante escaneo de QR.
- Validación de usuarios con **Google ID Token**.
- Gestión de clases y horarios académicos.
- Generación de reportes de asistencia por clase.
- Envío automático de reportes en PDF vía correo electrónico.
- Manejo de zona horaria local (Colombia GMT‑5) para registros consistentes.

---

## 🛠️ Tecnologías utilizadas

- **Node.js** – entorno de ejecución backend.
- **Express.js** – framework para la creación de APIs REST.
- **Firebase Admin SDK** – conexión con Firestore.
- **Google Auth Library** – validación de tokens de autenticación.
- **SendGrid** – envío de correos electrónicos con reportes.
- **Render** – despliegue del backend en la nube.
